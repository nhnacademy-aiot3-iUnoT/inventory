== Report API

저장소의 주간 리포트를 생성하고 조회합니다.

리포트는 월요일부터 일요일까지 7일을 한 주기로 집계하며,
입출고/폐기 수량, 구역별 환경 센서 요약, 구역별 문 개폐 요약, AI 요약으로 구성됩니다.

AI 요약은 리포트 생성과 별개로 비동기 처리되므로,
생성 직후 응답의 `aiSummary`는 `null`이고 `aiSummaryStatus`는 `PENDING`입니다.

=== 주간 리포트 조회

기간 시작일로 해당 주의 리포트를 조회합니다.

`periodStart`는 월요일이어야 하며, 리포트가 아직 생성되지 않았다면 `data`가 `null`인 성공 응답을 반환합니다.

=== 리포트 재생성

기존 리포트의 집계를 전부 버리고 다시 만듭니다.

리포트 ID는 유지되며, 집계 항목과 AI 요약이 초기화된 뒤 다시 채워집니다.

입고 내역이 뒤늦게 소급되었거나 집계가 잘못된 경우에 사용합니다.

=== AI 요약 재생성

집계는 그대로 두고 AI 요약만 다시 생성합니다.

요약 생성이 실패(`FAILED`)했을 때 재시도하는 용도입니다.

비동기로 처리되므로 응답 본문 없이 204를 반환하며,
진행 상태는 리포트를 다시 조회해 `aiSummaryStatus`로 확인합니다.
