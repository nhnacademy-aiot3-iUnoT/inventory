== 재고 관리 API

재고의 조회와 입고 등록 기능을 제공합니다.

재고 조회 API는 공통 응답 형식인 `ApiResponse`를 사용하며, 목록 데이터는 `PageResponse`로 반환합니다.

=== 공통 응답 형식

성공 응답은 `success=true`와 `data`를 포함합니다. 오류가 발생하면 `success=false`와 `error`가 반환됩니다.

모든 페이지 응답은 다음 정보를 포함합니다.

* `content`: 조회 결과
* `page`: 현재 페이지 번호(0부터 시작)
* `size`: 페이지 크기
* `totalElements`: 전체 결과 수
* `totalPages`: 전체 페이지 수
* `last`: 마지막 페이지 여부
