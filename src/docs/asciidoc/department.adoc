= Department API

== 부서 관리

부서는 조직에 소속된 구성 단위입니다.

OWNER 권한을 가진 조직원만 부서를 생성, 수정, 상태 변경, 삭제할 수 있으며,
조직에 소속된 모든 조직원은 부서 목록 및 상세 정보를 조회할 수 있습니다.
